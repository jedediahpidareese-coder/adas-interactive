Deployment Guide

Use a public HTTPS host so your QR code works for anyone, anywhere.

Back To Simulator

GitHub Pages (Persistent)

  1. Create a new GitHub repo and upload `index.html`, `style.css`, `app.js`, `cases.html`, `cases.js`, `case-library.js`, and `deploy.html`.
  2. In GitHub, open `Settings` -> `Pages` -> set source to `Deploy from a branch` and choose `main` / root.
  3. Wait for build, then copy your URL like `https://yourname.github.io/repo-name/`.
  4. Paste that URL into the QR panel `Class URL` field and regenerate QR.

Cloudflare Pages / Netlify / Vercel (Persistent)

  1. Create a site from this folder (static site, no build command required).
  2. Use the generated HTTPS URL for QR.

Temporary tunnels can be useful for demos, but for semester-long access use persistent hosting.
